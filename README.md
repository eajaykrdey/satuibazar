# Satuibazar - Hyperlocal & Lifestyle E-Commerce Platform

A multi-vendor e-commerce platform built with React, Vite, TypeScript, Express, and Google Gemini API.

## Features
- **Storefront:** Curated electronics, Bengal handloom fashion, groceries, fresh produce, puja items, and daily essentials.
- **Multi-Vendor System:** Vendor-tagged items, shop-filtered browsing, and shop-wise order grouping.
- **Role-Based Portals:** Customer account management, Shop Owner inventory & order management, and Admin control.
